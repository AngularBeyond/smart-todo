An Agentic Blueprint

The Agentic way of building modern applications in Angular.

Smart Todo is an open-source reference template demonstrating how to adopt Generative UI in a real-world Angular app. Explore how AG-UI (Agent-to-User Interface) and A2UI (Agent-to-UI orchestration) interact with reactive SignalStores, transactional backends, and accessible design systems.

Explore the code. Adopt the pattern. Build the future.
