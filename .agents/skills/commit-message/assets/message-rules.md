# Commit Message Rules

## Format & Structure
- **Format**: Plain action phrase describing the primary change (`<Action description>`).
- **Ticket / Story Prefix**: **FORBIDDEN**. Do NOT include JIRA IDs, Story IDs (e.g. `STORY-2.5:`), or ticket prefixes in the commit message.
- **Conventional Commit Type**: **FORBIDDEN**. Do NOT prefix with `feat:`, `fix:`, `refactor:`, `chore:`, etc.
- **Line Count**: Exactly 1 line. No body, no footers, no bullet points.
- **Length**: Maximum 15 words.
- **Ending**: Do NOT include a trailing period or punctuation.
- **Emojis**: Forbidden.

## Verb Tense & Casing
- **Verb Tense**: Use gerund / present participle verbs ending in `-ing` (e.g., `Refactoring`, `Updating`, `Fixing`, `Aligning`, `Implementing`, `Adding`), or imperative verbs (`Connect`, `Implement`, `Initialize`).
- **Capitalization**: Capitalize the first letter of the commit message.
